# Малыш — трекер для новорождённого

Приложение для iPhone, Android и браузера: сон, кормление, подгузники, звуки для засыпания,
рост и вес по ВОЗ, лекарства и прививки. Всё офлайн, данные только на телефоне.

Код на Kotlin Multiplatform: логика и весь интерфейс (Compose Multiplatform) общие для всех трёх,
по-своему на каждой платформе только уведомления, фоновый звук, виджет и работа с файлами.
Веб-версия — тот же код, собранный в Kotlin/Wasm: https://a77m8123.github.io/baby-tracker/

## Что умеет

**Сегодня**
- Спит / бодрствует с таймером; окно бодрствования по возрасту — когда укладывать
- Кормление грудью с секундомером для левой и правой, пауза, «с какой начинать»
- Бутылочка (смесь / сцеженное, мл), прикорм с подсказками недавнего
- Подгузник: мокрый, грязный или оба
- Сводка за день: сон против цели, кормления, подгузники
- Лекарства, которые давали за сутки, и ближайшая прививка

**Дневник**
- Записи по дням, можно листать назад; любую запись можно изменить или удалить
- Добавление задним числом
- Неделя: графики сна (с целью), кормлений, бутылочки, подгузников и средние

**Звуки** — белый шум, сердцебиение, фен, дождь, волны, капли, колыбельная.
Синтезируются на лету, играют в фоне, громкость и таймер; в последнюю минуту плавно затихают.

**Здоровье**
- Замеры веса, роста, головы; график с коридором ВОЗ (−2…+2 SD) для мальчиков и девочек
- Лекарства: доза, минимальный интервал, кнопка «Дали», напоминание
- Прививки: заполнение по национальному календарю РФ от даты рождения, отметка «сделана»

**Ещё**
- Имя, дата рождения, пол; цель сна, интервал кормлений, объём бутылочки
- Напоминания: кормление, «пора укладывать», лекарства, прививки (накануне в 19:00)
- Тема: системная / светлая / тёмная; ночной режим (тёмно-красный, без синего) — всегда или с 21:00 до 7:00
- PDF-отчёт для педиатра за 7 / 14 / 30 дней, таблица CSV
- Резервная копия в файл и восстановление

**Виджеты**
- Android: виджет на рабочий стол с секундомером и кнопкой «Уснул / Проснулся»
- iPhone (iOS 16.1+): виджет «Домой» и экрана блокировки, Live Activity — таймер сна или кормления
  на экране блокировки и в Dynamic Island

## Структура

| Папка | Что внутри |
|---|---|
| `shared/src/commonMain` | модель, хранилище, логика (`logic/`), синтез звука, весь интерфейс (`ui/`) |
| `shared/src/androidMain`, `iosMain` | хранилище (SharedPreferences / NSUserDefaults), iOS-платформа: уведомления, звук |
| `androidApp/` | Activity, будильники, сервис звука, виджет, PDF, «Поделиться» |
| `iosApp/` | SwiftUI-обёртка, `AppBridge` (виджет, Live Activity, PDF, файлы), расширение `BabyWidget` |
| `webApp/` | веб-версия (Kotlin/Wasm): localStorage, Web Audio, уведомления браузера, печать отчёта |
| `site/` | сайт со ссылками на скачивание (для Vercel) |

## Сборка

GitHub Actions (`.github/workflows/build.yml`) на каждый push в `main`:
гоняет тесты, собирает `Malysh.apk` и `Malysh.ipa` и выкладывает их в релиз.
Ссылки на последнюю сборку не меняются:

- https://github.com/a77m8123/baby-tracker/releases/latest/download/Malysh.apk
- https://github.com/a77m8123/baby-tracker/releases/latest/download/Malysh.ipa

Веб-версию собирает `.github/workflows/web.yml` и выкладывает на GitHub Pages
(один раз: Settings → Pages → Source: **GitHub Actions**). Локально:
`.\gradlew :webApp:wasmJsBrowserDistribution` → `webApp/build/dist/wasmJs/productionExecutable`
(открывать через любой локальный сервер, например `python -m http.server`).

APK локально (нужны JDK 17 и Android SDK 35): `.\build-apk.ps1`.
Тесты локально из папки с кириллицей в пути не запускаются — они идут в Actions.

## Веб-версия: ограничения

- Данные в браузере этого устройства (localStorage); копию можно сохранить и восстановить в «Ещё».
- Напоминания — только пока вкладка открыта; виджетов нет.
- PDF-отчёт открывается в окне печати — там «Сохранить как PDF».
- Звук при заблокированном экране iPhone может прерываться.

## Установка на iPhone

Через [AltStore](https://altstore.io): скачать `Malysh.ipa` → AltStore → My Apps → «+».
Расширение виджета — отдельный App ID: с бесплатным Apple ID (3 приложения) AltStore
может предложить установить без него, тогда приложение работает без виджета и Live Activity.

## Сайт на Vercel

1. vercel.com → Add New → Project → импортировать репозиторий `baby-tracker`.
2. Root Directory: `site`, Framework Preset: **Other**, команду сборки не задавать.
3. Deploy. Дальше сайт обновляется сам при каждом push.

Кнопки скачивания работают, только если репозиторий публичный (или релизы открыты).

## Нормы

Сон в сутки, окна бодрствования, рост и вес ВОЗ, календарь прививок — общие ориентиры,
не медицинские рекомендации. Свою цель сна можно задать в настройках.

# Малыш — трекер для новорождённого

Android-приложение для родителей: сон, кормление, подгузник, звуки для засыпания.
Всё офлайн, данные только на телефоне.

## Что уже есть

**Главный экран**
- Спит / не спит, длительность текущего сна
- Прогноз пробуждения (по циклу сна)
- Сон за сегодня против цели на сутки
- Таймер до следующего кормления, счётчик кормлений за день, объём в мл
- Кнопки: Уснул / Проснулся, Грудь / Бутылочка / Прикорм, Подгузник
- Лента событий за всё время

**Звуки**
- Белый шум, Дождь, Капли, Колыбельная (Брамс) — всё синтезируется в реальном времени, аудиофайлов в APK нет
- Таймер автовыключения: бесконечно / 15 / 30 / 60 мин
- Играет в фоне при выключенном экране, управление из шторки

**Статистика**
- Сон по дням за неделю (полоски), средний сон, среднее число кормлений

**Настройки**
- Имя и дата рождения ребёнка
- Цель сна в сутки (по умолчанию — норма по возрасту)
- Цикл сна для прогноза пробуждения
- Интервал кормления, объём бутылочки по умолчанию
- Таймер звуков, вкл/выкл напоминаний

**Уведомления**
- Точный будильник на следующее кормление и на конец цикла сна
- AlarmManager + foreground service для звука

## Нормы сна по возрасту

| Возраст | Сон в сутки |
|---|---|
| 0–4 мес | 14–17 ч |
| 4–6 мес | 12–16 ч |
| 6–9 мес | 12–15 ч |
| 9–12 мес | 11–14 ч |
| 1–1.5 г | 10–13 ч |
| 1.5–2 г | 11–14 ч |
| 2–3 г | 10–13 ч |

Это общие ориентиры, не медицинские рекомендации. Своё значение можно задать в настройках.

## Сборка

Нужны JDK 17 и Android SDK (platform 35, build-tools 35.0.0).

```bash
cd baby-tracker
./gradlew :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

На Windows удобнее скриптом (сам подставляет JAVA_HOME и ANDROID_HOME):

```
powershell -File baby-tracker\build-apk.ps1
```

## Установка на телефон

1. Включить на телефоне «Отладку по USB» (Настройки → Для разработчиков)
2. Подключить кабелем, разрешить отладку

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Либо скинуть APK на телефон файлом и открыть (нужно разрешить установку из неизвестных источников).

При первом запуске приложение попросит разрешение на уведомления и, на Android 12+,
на точные будильники (`Настройки → Приложения → Специальный доступ → Будильники и напоминания`).

## Важное про путь проекта

Папка `мои проги` содержит кириллицу — Android Gradle Plugin такие пути не поддерживает.
В `gradle.properties` стоит обход `android.overridePathCheck=true`, но надёжнее перенести
проект в путь только из латиницы, например `C:\dev\baby-tracker`.

## Структура

```
app/src/main/java/com/babytracker/
├── BabyApp.kt              Application, БД, настройки
├── MainActivity.kt         Activity + навигация между экранами
├── data/                   Room entities, DAO, DataStore-настройки, нормы сна
├── alarms/                 AlarmManager: будильники, ресиверы
├── notifications/          Каналы и показ уведомлений
├── sound/                  Синтез звуков + foreground-сервис
├── ui/                     Compose-экраны, тема, вьюмодели
└── util/                   Форматирование времени и склонения
```

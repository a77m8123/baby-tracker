# Малыш — веб-версия

Та же программа, что и Android-приложение, но в браузере: сон, кормление, подгузник,
звуки, статистика за неделю, настройки. Работает офлайн, данные хранятся только
на телефоне (в браузере), на сервер ничего не уходит.

Код — TypeScript без фреймворков, сборка Vite. Логика перенесена из Kotlin один в один:

| Kotlin (app/)               | Веб (web/src/)   |
|-----------------------------|------------------|
| `util/TimeFmt.kt`           | `time.ts`        |
| `data/Settings.kt`, `SleepNorm.kt` | `norms.ts` |
| Room (`Entities`, `BabyDao`), вьюмодели | `store.ts` (localStorage) |
| `sound/Synth.kt`            | `synth.ts`       |
| `sound/SoundService.kt`     | `player.ts`      |
| `ui/*Screen.kt`             | `main.ts`, `style.css` |

## Запуск на компьютере

Нужен Node.js 20+.

```bash
cd web
npm install
npm run dev      # откроется на http://localhost:5173
npm test         # тесты логики и синтеза
npm run build    # готовая сборка в web/dist
```

`npm run dev` печатает и адрес в локальной сети (`Network: http://192.168.…`) — его можно
открыть с iPhone в той же Wi-Fi, чтобы быстро посмотреть. Офлайн-режим так не включится:
для него нужен https (GitHub Pages).

## Публикация

При push в ветку `main` GitHub Actions (`.github/workflows/web.yml`) собирает `web/`
и выкладывает на GitHub Pages. Один раз нужно включить:
Settings → Pages → Source: **GitHub Actions**.

## Установка на iPhone

1. Открыть адрес сайта в **Safari** (не в Chrome).
2. Кнопка «Поделиться» → **«На экран Домой»**.
3. Запускать с иконки — откроется как приложение, без адресной строки.

Данные у иконки и у вкладки Safari — раздельные. Пользуйтесь одним из двух (лучше иконкой).

## Ограничения веб-версии на iPhone

- **Напоминаний нет**: iOS не даёт сайтам ставить будильники.
- **Звук при выключенном экране** может остановиться через какое-то время — зависит от версии iOS.
  Таймер автовыключения при этом работает.
- Если удалить иконку с экрана, данные удалятся вместе с ней.

Всё это решает iOS-приложение (следующий этап).

## Иконки

`npm run icons` перерисовывает PNG в `public/icons/` (месяц со звездой, как в Android-версии).
